# 読みもののネタの山と書き方

予約タスク「読みもの書き（4サイト）」が、火曜と土曜にここから1本ずつ書く（決めたのは 11/4、claude/sodatsu-spec.md）。このファイルと CLAUDE.md だけで1本書けるようにしてある。ネタの題は 11/4 にしょーくんが OK した。

## 書き方

### 置く場所と作り方
- 1本＝ページ1つ。URL は `/sonae/<英字>/`（「備えの知識」の読みもの）。今の5本（地震の前に足すもの・在宅避難・赤ちゃんと高齢の家族・ひとり暮らし・マンション）と同じ形にする。ひな形は `src/pages/sonae-yomimono.mjs` の「地震の前に足すもの」
- 足す所
  1. `src/pages/sonae-yomimono.mjs` の `YOMIMONO` に `{ key, path, name, group, date }` を1行（key は英字からハイフンを外したもの。date は PR を作る日の 'YYYY-MM-DD'）。group は /sonae/ の棚の見出しで「量と品目」「災害の前に」「家族と住まい」「家の外」のどれか。災害の種類の名前が題にあれば「災害の前に」、家族や住まいの形が題にあれば「家族と住まい」、それ以外は「量と品目」。この1行で /sonae/ の棚と、同じ group の読みものの末尾と、RSS（/sonae/feed.xml）に出る
  2. 同じファイルの `yomimonoPages()` に `out.push({...})` を1つ。中の並び：crumb → `<h1 class="city">` → `<p class="lead">`（1行） → `${CALC}` → `table([...], rows)`（「起きること／前に足すもの」か「止まるもの／代わりに足すもの」。4〜6行） → `<div class="prose">` の h2 と p → `${tail(items, key)}` → `<p class="why">`（起きてからの動き方は気象庁・市区町村・ハザードマップで確かめる、の1行） → `h2('出典')` と `sourceList(items.<key>.sources, sources)`。head は `<style>${CSS}</style>`
  3. `data/items.yml` に `<key>:` と `sources: [...]` を足す（`checkYomimono()` が YOMIMONO の全部を見張る）。新しい数字が要るときも items.yml に足して出典をつける
  4. `data/sources.yml` に新しい出典（id・kind: sonae・publisher・title は開いて確かめた題そのまま・url・checked は開いた日・about は自分の言葉で短く）。今の行の形をまねる
- 数字：備えの数字は `cc`（`cc.by.mizu.per_day`・`cc.days` など）と `items.yml` から。国勢調査の全国の値が要るネタは、`scripts/build.mjs` の `yomimonoPages({ cc, items, sources })` に `z`（全国の値。build.mjs にある）を足して渡す。避難場所の全国の数は `data/hinan/counts.json` の合計。本文に数字を直接書かない
- コマンド：`npm run check`（テスト → ビルド → 全ページ点検）。作業場から国土地理院に届かないので、避難場所の一覧がないと言われたら `ALLOW_MISSING_HINAN_LIST=1 npm run check`。地の文の字数は `node scripts/honbun.mjs dist --pages` のあと、そのページの行を見る（左が地の文・右が本文）
- ブランチは `claude/yomimono-<英字>`。PR は1本に1つ。このファイルの山の行も同じ PR で `- [x]` にする

### 中身
- だれの問いに答えるか：「わが家は、その災害や暮らしの形のために、前に何を足しておけばいいか」。1本に1つのテーマ
- 長さ：地の文（`node scripts/honbun.mjs dist --pages` の左の数。表・見出し・出典は数えない）900字以上。文字を増やすための水増しはしない（AdSense のやり直し中。11/8・claude/machi-adsense-plan.md）
- 1画面めは、題・1行のリード・計算への入口。表と本文はその下
- 出典：公的な発行元（内閣府・消防庁・気象庁・国土交通省・農林水産省・厚生労働省・都道府県・市区町村など）を2つ以上。開けて題を確かめたものだけ使う。開いたページに書いてないことは書かない。日付や回数などの数字は出典の言い方のまま
- 書かないこと
  - 災害が起きている最中の動き方・避難するかの判断（最後の1行で気象庁・市区町村・ハザードマップへ）
  - 街どうしの危険度のくらべ。避難場所の数を人口あたり・順位・街どうしのくらべに使うこと
  - 「今すぐ」「手遅れ」のようにあおる言葉。赤と黄の警告の色
  - 商品名・商品のくらべ（品目ページへのリンクはよい）。A8 などの広告は置かない
  - 薬の量や飲み方などの医療の判断（「主治医や薬剤師に相談」の1行にする）
  - 作り話の体験談・運営者の経験（machi は運営者の経験を出さない）
- 文章（site-principles の「文章」）
  - キャッチコピーを書かない。何をどれだけ足すかを、ふつうの言葉と具体的な例で書く
  - 使わない言葉：「〜しましょう」「ぜひ」「便利」「簡単」「安心」「おすすめ」「ポイント」「コツ」、3つ並べの言い回し、「まず・さらに・また」の続け書き、ダッシュ（——）、絵文字
  - 太字と箇条書きを多用しない。かっこは1文に1つまで。語尾と文の長さをそろえすぎない
  - 「使い方」の節は作らない。h2 は中身の言葉（「水とトイレ」「家具とガラス」のように）
  - 子どもも読むサイトなので、むずかしい言葉には短い言いかえをつける
- 最後につなぐもの：`tail()` が品目・チェックリスト・ほかの読みものを出す。本文の中でも、関係する道具（/dougu/keisan/ 計算・/dougu/check/ チェックリスト・/dougu/kigen/ 期限メモ・/dougu/karte/ 防災カルテ）か読みもの1つへ、自然に1回つなぐ（site-principles の「AIの検索の答えに負けない作り」）

### 絵
- 使わない。表の川の印（SVG）だけで、今の読みものと同じ見た目にする。Canva は使わない

### 公開
- main への push で `deploy.yml` が動いて公開される（マージで公開）。ほかに動かす workflow はない
- PR の点検（check・build-deploy・リンクの点検）が緑になってから squash でマージする

### 書いていない人の点検で見ること
- 出典のページに書いてないことを書いていないか・数字が items.yml と同じか
- 書かないこと（起きてからの動き方・あおる言葉・医療の判断・商品）と使わない言葉
- 1画面め（スマホ 390×660）に題・リード・計算への入口が入っているか

### ネタの選び方（山が5本を切ったら、予約タスクが10本足す）
- よいネタ
  - 災害の前に、家に足しておくもの（災害の種類・季節）
  - 家族の形と住まいの形（国勢調査の項目：ひとり暮らし・65歳以上の人がいる世帯・共同住宅・一戸建て・世帯の人数）とつながるもの
  - これから3か月のうちに来る行事や季節の備え（1/17・3/11・梅雨・台風・9/1・11/19 など）
- だめなネタ
  - 起きてからの動き方・避難の判断だけになるもの
  - 危険度で街をくらべるもの、市区町村ごとの読みもの（読みものは全国向け）
  - 商品の紹介・くらべ
  - ペット（環境省の正式版が出るまで）、医療の判断が中心になるもの
  - 今ある読みもの（/sonae/ の一覧）と、この山にある題と同じテーマ
- 足すときは、/sonae/ の一覧とこの山の題を全部読んでから。出典の候補の URL がわかれば行に書く

## ネタの山
上から順に書く。行の「／」のあとは使う資料（出典の id は data/sources.yml にあるもの。ないものは WebSearch で公式のページを探す）。

- [x] 年に2回の備えの見直し（PR #66・2026-11-07）
- [x] 火事の備え（PR #84・2026-11-10）
- [ ] 断水の備え（英字 dansui）— 飲み水のほかに、トイレや体をふく生活用水をどう用意するか／miyagi-mizu・chiba-zaitaku・hiroshima-toilet・kanagawa-toilet。くみ置きのしかたは自治体の公式で確かめる
- [ ] 非常用持ち出し袋と家の備蓄のちがい（英字 mochidashi）— 袋に入れるものと家に置くものをどう分けるか／nagasaki-mochidashi・osaka-bichiku・kantei-sonae。チェックリスト（持ち出す袋）へつなぐ
- [ ] 家族の連絡のしかた（英字 renraku）— 家族がばらばらの時間に起きたら、どう連絡して、どこで会うか（災害用伝言ダイヤル171・集まる場所）／NTT東日本・西日本の災害用伝言ダイヤルの公式ページ（WebSearch）・kantei-sonae。体験できる日は出典の言い方のまま
- [ ] 世帯の人数と備蓄の量（英字 setai-ninzu）— 1世帯の人数（国勢調査）で、家に置く水と携帯トイレの量がどう変わるか／kokusei-2025・maff-sonae。全国の1世帯の人数と県の幅はサイトのデータ（build.mjs の z と県の値）から。計算（/dougu/keisan/）へつなぐ
- [ ] 指定緊急避難場所と指定避難所のちがい（英字 hinanbasho）— 2つの言葉のちがいと、家の近くの場所の確かめ方／gsi-hinanbasho・gsi-menseki・内閣府の避難の説明（WebSearch）。全国の数は data/hinan/counts.json の合計と取得日。人口あたり・順位・街くらべにしない
- [ ] 一戸建ての家の備え（英字 ikkodate）— 一戸建てで前に足すもの（家具の固定・屋根や窓・物置の備蓄の置き場所・耐震診断の相談先）。マンションの読みものと対に／tfd-jishin・ota-kanshin・chiba-zaitaku・bousai-teiden。一戸建ての世帯の割合（国勢調査・全国の値）はサイトのデータから
- [ ] 離れて暮らす親の備え（英字 hanarete）— ひとり暮らしの高齢の家族のために、離れた家族が前にできること（連絡の決めごと・備蓄の量・薬）／maff-tanshin・nerima-yohairyo。65歳以上のひとり暮らしの世帯の割合（国勢調査・全国の値）はサイトのデータから。赤ちゃん・高齢の家族の読みものと家族の連絡のしかたへつなぐ
- [ ] 薬と持病の備え（英字 kusuri）— 毎日飲む薬・お薬手帳・持病のある人が前に用意しておくもの／厚生労働省か都道府県・市区町村の公式（WebSearch）・maff-tanshin。量や飲み方は書かず「主治医や薬剤師に相談」の1行
- [ ] 衛生の備え（英字 eisei）— 断水のときの歯みがき・からだふき・生理用品・ごみ袋／自治体の公式（WebSearch）・kanagawa-toilet・hiroshima-toilet
- [ ] 食物アレルギーのある家の備え（英字 allergy）— アレルギーのある家族の食べ物をどう備えるか（家で多めに・表示の見方）／maff-guide・maff-tanshin・消費者庁の食物アレルギー表示のページ（WebSearch）
- [ ] 子ども（小学生）がいる家の備え（英字 kodomo）— 学校にいるときの引き渡し・子どもと前に決めておくこと・子どもの持ち物／文部科学省か自治体の公式（WebSearch）・kantei-sonae。まなびプリント（/dougu/manabi/）へつなぐ
- [ ] 寝室と玄関に置くもの（英字 okiba）— 夜の地震に備えて寝室に置くもの、玄関に置くもの、備蓄を家の中で分けて置く考え方／tfd-jishin・kantei-sonae・nagasaki-mochidashi
- [ ] 停電のときの情報の取り方（英字 joho）— ラジオ・乾電池・スマホの充電・自治体の防災メールの登録を前にしておく／bousai-teiden・caa-hakkaden・mlit-lifeline
- [ ] ハザードマップの見方（英字 hazard-map）— 色と記号の読み方、自宅と職場・学校の場所の確かめ方／disaportal・国土交通省の重ねるハザードマップ（WebSearch）。危険度の街くらべと避難の判断は書かない（市区町村のハザードマップと案内へ）
- [ ] 火山の灰の備え（英字 kazanbai）— 火山の灰が降る前に家に足すもの／内閣府・気象庁の降灰の説明（WebSearch）。足すものは出典にあるものだけ
- [ ] 大雨と浸水の前に足すもの（英字 ooame）— 浸水に備えて家の中で前にしておくこと（家財の置き場所・土のうや水のう・停電と断水）／disaportal・mlit-lifeline・国土交通省か自治体の浸水対策のページ（WebSearch）

- [ ] 夏の停電と暑さの備え（英字 natsu-teiden）— 夏に電気が止まったときの暑さと水と食べ物。冬の停電と寒さの備えと対に／環境省の熱中症の情報サイト（WebSearch）・bousai-teiden・caa-hakkaden
